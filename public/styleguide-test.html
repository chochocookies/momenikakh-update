Font Implementation

Font yang akan digunakan:

  • Cormorant Garamond - Serif untuk heading dan elemen dekoratif
  • Plus Jakarta Sans - Sans-serif untuk body text dan UI

Langkah Selanjutnya untuk DS-02

  1. Jalankan script download font: npm run fonts:download
  2. Verifikasi font ada di public/fonts/
  3. Buka /styleguide untuk melihat token display
  4. Periksa Network tab untuk memastikan tidak ada request ke fonts.googleapis.com

File yang Telah Dibuat

  • resources/css/tokens.css - Semua token desain + font declarations
  • resources/views/styleguide/index.blade.php - Halaman styleguide lengkap
  • scripts/download-fonts.ps1 - Script download font (Windows)
  • scripts/download-fonts.sh - Script download font (Linux/Mac)
  • docs/font-self-hosting.md - Dokumentasi lengkap implementasi font
  • routes/web.php - Route untuk /styleguide
