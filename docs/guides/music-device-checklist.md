# Daftar periksa musik di ponsel sungguhan (MED-05)

Lakukan di minimal satu iPhone (Safari) dan satu Android (Chrome), memakai tautan undangan nyata di staging yang dikirim lewat WhatsApp (buka dari dalam peramban dalam aplikasi WhatsApp dan dari Safari/Chrome).

| # | Langkah | Hasil yang diharapkan | iOS | Android |
|---|---|---|---|---|
| 1 | Buka tautan | Tidak ada suara sebelum menyentuh apa pun | | |
| 2 | Tombol musik terlihat, label "Putar musik" | Ya, mudah disentuh | | |
| 3 | Ketuk "Buka undangan" | Musik mulai dalam 1 detik | | |
| 4 | Ketuk tombol musik | Musik berhenti, label berubah "Putar musik" | | |
| 5 | Ketuk lagi | Musik lanjut | | |
| 6 | Kunci layar 10 detik, buka kembali | Tidak ada suara saat terkunci; tombol tetap bisa dipakai | | |
| 7 | Pindah ke aplikasi lain lalu kembali | Musik tidak bocor saat di latar; bisa dilanjutkan | | |
| 8 | Mode senyap (iPhone: sakelar samping) | Catat apakah suara tetap keluar (perilaku HTML audio) | | |
| 9 | Jaringan lambat (3G/Throttled) | Tombol tidak macet; musik mulai setelah buffer | | |
| 10 | Matikan jaringan lalu ketuk buka | Tombol menjadi "Musik tidak tersedia" tanpa error di halaman | | |
| 11 | Mode hemat daya / Data Saver aktif | Musik tetap bisa dimulai lewat ketukan | | |
| 12 | Buka dua undangan berurutan | Tidak ada dua musik bersamaan | | |

Catat versi OS, peramban, dan hasilnya di PR. Bila ada baris gagal, jangan tandai MED-05 selesai.
