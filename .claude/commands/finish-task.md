---
description: Tutup tugas dengan bukti
---
1. Jalankan `./vendor/bin/pint --test`, `./vendor/bin/phpstan`, `php artisan test`, `npm run build`. Laporkan keluaran nyata.
2. Periksa setiap kriteria "Selesai bila". Tandai `[x]` hanya bila terbukti; jika tidak, biarkan `[~]` dan sebut yang kurang.
3. Perbarui `docs/10-changelog.md` (satu baris dengan ID tugas) dan `docs/09-keputusan.md` bila perlu.
4. Jalankan `/review-diff`, lalu siapkan pesan commit `feat(<ID>): ...`.
